LANGKAH 2 — CEK TIMNYA
━━━━━━━━━━━━━━━━━━━━
```
d tm
```
Panel menampilkan komposisi tim aktif beserta tombol:
• ◀ ▶ — pindah ke tim sebelumnya / berikutnya
• menu pilih — lompat langsung ke tim tertentu
• 🗑️ Hapus — hapus tim yang sedang tampil (ada konfirmasi)

Lihat semua tim beserta ID-nya:
```
d team list
```
Tim bertanda ✅ adalah tim aktif. Ganti tim aktif:
```
d team pick 2
d team pick Rocket
```
Tim yang masih kosong tidak bisa dipakai simulasi; bot akan menolak.

━━━━━━━━━━━━━━━━━━━━
LANGKAH 3 — JALANKAN SIMULASI
━━━━━━━━━━━━━━━━━━━━
Setiap `d sim` menjalankan 50 pertarungan lalu menampilkan statistiknya. Jumlahnya bisa diubah dengan `-m`.

▸ Lawan tim milikmu sendiri
```
d sim                  → tim aktif vs salinan dirinya sendiri (mirror)
d sim 2                → tim aktif vs tim ID 2
d sim Blue             → tim aktif vs tim bernama Blue
d sim 1 vs 2           → tim ID 1 vs tim ID 2
d sim Rocket vs Blue   → memakai nama tim
```

`mirror` artinya tim diadu dengan salinan persisnya. Berguna untuk melihat seberapa besar pengaruh RNG: kalau winrate jauh dari 50%, berarti urutan serangan ikut menentukan.

▸ Lawan dari dex atau stat manual (tanpa perlu bikin tim lawan)
```
d sim snail level=60
d sim hp=14,att=6,pr=2,wp=3,mag=0,mr=1 level=60
```

▸ Atur jumlah pertarungan
```
d sim -m 100
d sim 1 vs 2 -m 200
```
Makin banyak, makin stabil angka winrate-nya. Batasnya 200 per perintah untuk user biasa.
